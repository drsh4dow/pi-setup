# Credits

The menu of visuals in `VISUALS.md` (pseudocode, call trees, component trees,
file trees, Mermaid, diffs) and its placement guidance come from
[Dex Horthy](https://github.com/dexhorthy)'s
[`show-me`](https://github.com/humanlayer/humanlayer) skill, reproduced almost

dependency would break standalone installs), so the content is copied in rather
than pointed at; this file is the attribution a dependency would otherwise have
carried.

The section structure (Problem, Change, Verification, Scope), the
behavior-phrased titles, and the evidence rules follow the
[t3code PR template](https://github.com/pingdotgg/t3code/blob/main/.github/pull_request_template.md)
and its merged PRs. Review notes and reviewer steps follow the 3Y Health PR
convention.
