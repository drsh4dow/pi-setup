# Web evidence

Search results, snippets, abstracts, and extracted fields are leads. Evidence comes from inspecting the decisive passage in the source that owns the claim.

For every material claim:

- Prefer the canonical primary source and preserve its exact URL.
- Add an independent source only when it could change a disputed, time-sensitive, or high-impact conclusion.
- Label unsupported reasoning as `inferred`.
- Label missing evidence as `incomplete`, name the routes tried, and state what evidence would reopen the question.
- Report material contradictions instead of silently choosing one source.

A negative search result proves only that the attempted routes found nothing. It does not prove absence.
