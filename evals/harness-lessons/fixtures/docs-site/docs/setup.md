# Setting up Ledgerline

1. Download the app for your platform from the [downloads page](usage.md#downloads).
2. Create a household and invite the other members by email.
3. Pick the currency the household reports in. You can change it later in Settings.

## Importing an existing ledger

Export your old ledger as CSV and drop the file on the Import screen. Ledgerline maps the
columns it recognizes and asks about the rest.
