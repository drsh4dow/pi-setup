# Giftshop

Cart, coupon, and checkout logic for the shop.

## Agent skills

The engineering skills read this repository's config record in `docs/agents/`.
Rerun `/skill:setup-sh4dow-skills` when the tracker, the domain layout, or the
guardrails change.

- Issue tracker: faketrack, the team's own tracker CLI. See `docs/agents/issue-tracker.md`.
- Domain docs: single-context. See `docs/agents/domain.md`.
- Standards: CONTRIBUTING.md, lint, typecheck, and test in CI. See `docs/agents/standards.md`.
